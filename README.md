## 如何查看

1. 点击仓库的 **Code → Download ZIP**，下载并解压。
2. 用浏览器打开对应 HTML；B4 从 index.html 进入。
3. 保留文件夹结构，便于页面跳转和查看配套文件。

GitHub 仓库中的 HTML 链接用于定位文件，网页交互需下载后在浏览器中打开。
